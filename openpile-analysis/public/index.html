How to assign a soil model

The mapping connects each exact workbook soil label to an OpenPile lateral soil model and selects which extracted fields supply its parameters. This app currently supports API_clay and API_sand only. Rock and other models are not supported by this CLI.


  1. Keep the soil label shown in the JSON unchanged. One mapping applies to every layer with that exact label; each layer supplies its own parameter values.
  2. Select its model and parameter fields in the controls below, or import reviewed project settings. The JSON is generated automatically.
  3. Choose static or cyclic for kind. This selects the soil curve formulation; it does not perform a load-history or residual-displacement analysis.
  4. Click Validate selected case to check the mapping and required layer values before running. Validation checks the selected footing and embedment, not every footing in the workbook.

Sand friction angle comes directly from each layer's friction_angle in degrees. Both models use layer depths and density. The strings above select workbook fields; do not substitute numeric strength or modulus values in the mapping. The CLI converts prepared units to solver units.


Complete JSON syntax example (replace the example labels with your exact labels; parameter choices are illustrative):


{
  "EXAMPLE CLAY": {
    "model": "API_clay",
    "kind": "static",
    "cohesion": "cohesion_ultimate",
    "strain": "e50",
    "J": 0.5
  },
  "EXAMPLE SAND": {
    "model": "API_sand",
    "kind": "cyclic",
    "modulus": "k_cyclic"
  }
}


For static sand, change both kind to static and modulus to k_static or k_static_factored. For cyclic clay, change kind to cyclic; the clay fields remain required. Factored fields are used as extracted; the mapping does not apply an additional factor. Missing required data must be supplied in the workbook and re-extracted. Leave unresolved or unsupported labels as null.


See the OpenPile model documentation for model definitions. A valid mapping does not establish the model's suitability for the site's soils.
